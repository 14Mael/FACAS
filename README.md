# FACAS 财务数据自动化工具

FACAS v1.0.1 面向企业财务人员，自动从 ERP 读取销售单和凭证探测器数据，按日期范围整理并生成 Excel，也可以批量保存 ERP 原版单据 PDF。程序使用 PySide6 提供现代化桌面界面，并提供运行日志和异常提示，无需命令行操作。

## 一、首次使用准备

1. 打开 `FACAS.exe`；开发运行时可使用 `python app.py`。程序会启动专用 Microsoft Edge。
2. 在新打开的 Edge 中登录 ERP，登录成功后保持浏览器和 ERP 页面打开，再回到 FACAS 操作。
3. 如果需要保存原版票据 PDF，在 ERP 的“打印机设置”中将“票据打印”设置为 `Microsoft Print to PDF`。Windows 未安装该打印机时，请先在系统中添加。
4. 选择需要处理的日期范围。

程序默认在自身所在目录创建以下文件夹：

- `output/Excel/`：导出的 Excel 文件
- `output/PDF/`：保存的票据 PDF 文件
- `log/`：按日期保存的运行日志

## 二、导出销售数据

1. 在“销售分类”区域勾选 `现场销售`、`库房销售`、`拆解料销售` 中需要处理的项目。
2. 根据需要启用 Excel 输出和 PDF 输出。
   PDF 默认生成 A4 竖版；勾选输出设置中的 `A5横版` 后，将按 A5 横版生成。
3. 点击“开始提取”。程序会自动进入销售管理模块，设置日期筛选，读取全部分页，并打开单据详情读取数据。
4. 任务完成后，只有在实际生成文件时才会自动打开输出目录。

销售 Excel 每张销售单占一行，包含销售分类、日期、单号、客户、物料名称、回收单号、总金额、税金、总重量、收款日期和详情备注等字段。现场销售只读取详情中的第一条物料和第一条回收单号；库房销售、拆解料销售不提取回收单号。税金优先读取详情税金合计，合计为 0 时自动累加物料明细税金。

## 三、银行流水处理与凭证录入

1. 在 FACAS 主窗口点击“银行流水录入”，选择银行流水 Excel。
2. 选择是否自动生成摘要并设置输出目录，点击“① 开始处理”生成中间 Excel。
3. 检查中间文件后点击“② 开始录入 ERP”；录入前需先通过主窗口启动并登录专用 Edge。银行录入与销售提取共用该 Edge，运行期间两项任务互斥。
4. 银行科目码可在银行录入窗口设置；程序按行生成凭证号并逐条录入，“不需要录入凭证”列填写 1 的行会跳过。

银行流水模板需包含“交易日期、摘要、对方账户名称、对方账号、借方发生额、贷方发生额、附言”列。中间文件默认保存在选定输出目录，自动生成摘要时保存为 `processed_statement.xlsx`，保留原摘要时保存为 `processed_statement_keep.xlsx`，同名文件不会被覆盖。

## 四、导出凭证探测器数据

1. 在“凭证类型”区域勾选 `综合付款单`、`车辆付款单`、`采购单` 中需要处理的项目。
2. 根据需要启用 Excel 输出和 PDF 输出。
3. 点击“开始提取”。程序会自动进入“财务管理 → 凭证处理 → 凭证探测器”，并按类型打开对应列表。
4. 程序按单据日期在指定范围内筛选，读取全部分页，并尝试双击打开每张单据详情保存 PDF。

凭证 Excel 字段顺序为：`票据号码`、`单据日期`、`对方单位`、`结算方式`、`完成日期`、`金额`、`制单`。

## 五、查看运行状态和日志

主界面日志会显示登录、筛选、分页、详情读取、文件生成和错误信息，并自动滚动到最新记录。完整日志保存在 `log/当天日期.log`。反馈问题时，请同时提供日志、操作日期范围和勾选的单据类型。

## 六、常见问题

- **提示“请在新窗口登录 ERP”**：专用 Edge 已启动但尚未登录，请完成登录后再次点击“开始提取”。
- **提示无法连接 `127.0.0.1:9222`**：专用 Edge 未启动或已关闭，关闭 FACAS 后重新打开程序。
- **提示日期范围内无数据**：确认日期范围、业务分类以及 ERP 中是否确实存在符合条件的单据。无数据时不会生成空 Excel。
- **PDF 未生成或提示无打印机**：确认 Windows 已安装 `Microsoft Print to PDF`，且 ERP“打印机设置”已选择该打印机。
- **出现 `SET_LICENSES` 或 LODOP 错误**：这是 ERP 自身打印组件异常，需要修复或安装 ERP 要求的 LODOP/CLodop 组件；Excel 导出通常不受影响。
- **没有自动打开输出目录**：本次没有实际生成 Excel 或 PDF 时不会打开目录，属于正常行为。

## 七、操作注意事项

- 任务运行期间不要关闭 FACAS、专用 Edge 或 ERP 页面。
- 不要手动切换 ERP 页面、点击列表或修改筛选条件，以免影响自动化流程。
- 每次运行前确认日期范围和勾选项，避免重复导出。
- ERP 页面、接口字段或打印组件发生变化后，自动化可能需要适配，请保留日志后反馈。

## 八、开发运行

安装依赖：

```powershell
python -m pip install -r requirements.txt
```

直接运行：

```powershell
python app.py
```

也可以使用 `run-facas.ps1` 启动；该脚本支持透传命令行参数，并减少在工作区生成 Python 缓存文件。
